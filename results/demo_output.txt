== Multiply-adds one layer spends on attention per generated token
 cached tokens              MHA      MLA, unpack    MLA, absorbed
            32         1.05e+06         5.38e+08         2.10e+07
         4,096         1.34e+08         6.89e+10         5.54e+08
       131,072         4.29e+09         2.20e+12         1.72e+10
The unpack path pays for rebuilding keys and values on every token. The absorbed path pays a fixed translation plus dot products that are 4x longer than MHA's. Memory, not multiply-adds, is the bottleneck when generating, so MLA trades bytes for arithmetic.
